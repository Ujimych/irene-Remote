# irene-Remote

Клиентское приложение для Raspberry Pi, предназначенное для подключения к голосовому серверу **Irene** (форку от AlexeyBond [https://github.com/AlexeyBond/Irene-Voice-Assistant]) через WebSocket.

Клиент обеспечивает:

* передачу аудио с микрофона на сервер;
* получение и воспроизведение голосовых ответов сервера;
* управление внешним MPD-плеером;
* автоматическую остановку MPD во время голосового ответа;
* восстановление воспроизведения MPD после ответа;
* управление аппаратной громкостью звуковой карты;
* индикацию состояния соединения и ожидания ответа с помощью светодиода;
* автоматическое переподключение при потере соединения с сервером.

Проект рассчитан на работу на **Raspberry Pi** с установленной звуковой картой **Seeed 2-Mic Voice Card**.

## Принцип работы

Клиент устанавливает WebSocket-соединение с сервером Irene:

```text
Raspberry Pi
     │
     ├── Seeed 2-Mic Voice Card
     │       ├── микрофон
     │       └── динамик
     │
     ├── irene-Remote
     │       │
     │       └──── WebSocket ────► Irene Server
     │
     └── MPD
```

После запуска клиент подключается к серверу и проходит процедуру согласования возможностей.

При успешном подключении светодиод выключается.

Когда сервер отправляет голосовой ответ:

1. клиент получает ссылку на WAV-файл;
2. скачивает WAV с сервера;
3. при необходимости останавливает MPD;
4. воспроизводит WAV через ALSA;
5. после окончания воспроизведения восстанавливает MPD, если музыка играла до голосового ответа;
6. удаляет временный WAV-файл.

Передача голоса с микрофона выполняется через отдельное WebSocket-соединение, которое сервер предоставляет после готовности серверной STT-службы.

## Индикация светодиодом

Светодиод подключён к GPIO Raspberry Pi.

Используется следующая индикация:

| Состояние                                                 | Светодиод       |
| --------------------------------------------------------- | --------------- |
| Сервер недоступен                                         | Постоянно горит |
| Подключение к серверу установлено                         | Выключен        |
| Отправлена команда управления громкостью, ожидается ответ | Мигание         |
| Ответ на команду получен                                  | Выключен        |
| Соединение потеряно                                       | Постоянно горит |

Таким образом, в обычном состоянии после подключения светодиод не горит.

## Требования

### Аппаратное обеспечение

* Raspberry Pi;
* Seeed 2-Mic Voice Card;
* подключённый динамик;
* микрофон звуковой карты.

### Программное обеспечение

* Raspberry Pi OS;
* Python 3;
* ALSA;
* MPD — если требуется воспроизведение музыки;
* доступ к серверу Irene по сети.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Ujimych/irene-Remote.git
cd irene-Remote
```

Создать виртуальное окружение:

```bash
python3 -m venv irene-Remote
```

Активировать его:

```bash
source irene-Remote/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Настройка

Основные параметры находятся в `config.yaml`.

Пример:

```yaml
# server
host: '192.168.1.132'
port: '8086'

# input (record)
buffersize_input: 100
device_input: 'seeed-2mic-voicecard'
blocksize_input: 8000
dtype_input: 'int16'
samplerate_input: 48000
channels_input: 1
```

### Параметры сервера

`host` — IP-адрес сервера Irene.

`port` — порт WebSocket-сервера.

### Параметры записи

`buffersize_input` — размер внутренней очереди аудиоданных.

`device_input` — устройство захвата звука.

`blocksize_input` — размер блока аудиоданных.

`dtype_input` — формат входных данных.

`samplerate_input` — частота дискретизации.

`channels_input` — количество каналов.

Для Seeed 2-Mic Voice Card используется монофоническая запись:

```yaml
channels_input: 1
```

## Запуск

После активации виртуального окружения:

```bash
python main.py
```

При успешном подключении в журнале появляется сообщение:

```text
Подключен к серверу!
```

После установления соединения светодиод выключается.

## Потеря соединения

Если сервер недоступен при запуске или соединение было потеряно, клиент не завершается.

Он:

1. включает светодиод;
2. освобождает связанные с соединением ресурсы;
3. приостанавливает запись;
4. закрывает дополнительное соединение передачи аудио;
5. пытается подключиться снова через 5 секунд.

При успешном восстановлении соединения светодиод выключается.

## Управление MPD

`mpd_player.py` обеспечивает управление локальным MPD через порт `6600`.

При воспроизведении голосового ответа используется следующая логика:

```text
MPD играет музыку
      │
      ▼
Пришёл голосовой ответ
      │
      ▼
MPD останавливается
      │
      ▼
Воспроизводится голосовой ответ
      │
      ▼
Голосовой ответ закончен
      │
      ▼
MPD запускается снова
```

Для остановки используется именно `stop()`, а не `pause()`.

Это необходимо для полного освобождения ALSA-устройства перед воспроизведением голосового ответа.

Если MPD не воспроизводил музыку до голосового ответа, после него MPD не запускается.

## Управление громкостью

`volume_control.py` управляет аппаратной громкостью звуковой карты через `amixer`.

Используется регулятор:

```text
Speaker
```

звуковой карты Seeed 2-Mic Voice Card.

Диапазон аппаратной громкости:

```text
0 ... 127
```

Предустановленные значения:

```text
Минимальная:  0
Средняя:      112
Максимальная: 127
```

При запуске клиента устанавливается средняя громкость.

Шаг изменения громкости:

```text
10
```

Поддерживаются команды:

* увеличение громкости;
* уменьшение громкости;
* минимальная громкость;
* средняя громкость;
* максимальная громкость;
* mute;
* unmute;
* установка конкретного значения.

После получения команды управления громкостью светодиод начинает мигать, показывая, что команда обрабатывается.

После получения и отправки результата светодиод снова выключается.

## Воспроизведение голосовых ответов

`player.py` получает WAV-файл с сервера и временно сохраняет его на локальном диске.

Воспроизведение выполняется через:

```text
aplay
```

с использованием ALSA-устройства:

```text
plughw:CARD=seeed2micvoicec,DEV=0
```

После завершения воспроизведения временный файл удаляется.

Ошибки загрузки или воспроизведения не приводят к завершению клиента.

## Запись с микрофона

`recorder.py` использует `sounddevice.RawInputStream`.

Аудиоданные:

1. поступают от звуковой карты;
2. помещаются во внутреннюю очередь;
3. извлекаются из очереди;
4. отправляются серверу через WebSocket.

Используется монофонический вход с частотой дискретизации 48 кГц.

Во время голосового ответа сервер может приостановить передачу микрофона через сообщения:

```text
in.mute/mute
in.mute/unmute
```

## Структура проекта

```text
irene-Remote/
├── config.yaml
├── gateway.py
├── main.py
├── mpd_player.py
├── player.py
├── recorder.py
├── requirements.txt
└── volume_control.py
```

### `main.py`

Точка входа приложения.

Создаёт и связывает основные компоненты клиента:

* Recorder;
* Player;
* MpdPlayer;
* VolumeControl;
* Gateway.

### `gateway.py`

Основной сетевой модуль.

Отвечает за:

* WebSocket-соединение с сервером;
* согласование протоколов;
* получение сообщений;
* обработку голосовых команд;
* обработку голосовых ответов;
* управление записью;
* управление светодиодом;
* автоматическое переподключение;
* индикацию ожидания ответа на команды громкости.

### `recorder.py`

Отвечает за захват аудио с микрофона и передачу аудиоданных серверу.

### `player.py`

Отвечает за:

* загрузку WAV-файлов;
* временное хранение;
* воспроизведение через ALSA;
* взаимодействие с MPD во время голосового ответа.

### `mpd_player.py`

Отвечает за управление локальным MPD.

### `volume_control.py`

Отвечает за аппаратное управление громкостью через ALSA `amixer`.

### `config.yaml`

Содержит настройки сервера и аудиовхода.

### `requirements.txt`

Содержит Python-зависимости проекта.

## Завершение работы

Для остановки клиента используется:

```text
Ctrl+C
```

При завершении приложение:

* останавливает запись;
* закрывает WebSocket-соединения;
* освобождает задачи asyncio;
* закрывает соединение с MPD;
* возвращает необходимые ресурсы GPIO.
