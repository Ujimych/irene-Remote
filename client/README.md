# irene-Remote

Клиентское приложение для Raspberry Pi, предназначенное для подключения к голосовому серверу **Irene** (форку от AlexeyBond [Irene-Voice-Assistant](https://github.com/AlexeyBond/Irene-Voice-Assistant)) через WebSocket.

Клиент обеспечивает:

* передачу аудио с микрофона на сервер;
* получение и воспроизведение голосовых ответов сервера;
* управление внешним MPD-плеером;
* автоматическую остановку MPD во время голосового ответа;
* восстановление воспроизведения MPD после ответа;
* управление аппаратной громкостью звуковой карты;
* установку громкости в пользовательских процентах от 0 до 100%;
* получение текущего уровня громкости;
* обработку голосовых команд управления громкостью;
* индикацию состояния соединения и ожидания ответа с помощью светодиода;
* автоматическое переподключение при потере соединения с сервером.

Проект рассчитан на работу на **Raspberry Pi** с установленной звуковой картой **Seeed 2-Mic Voice Card**.

## Принцип работы

Клиент устанавливает WebSocket-соединение с сервером Irene:

```text
Raspberry Pi
     │
     ├── Seeed 2-Mic Voice Card
     │       ├── микрофон
     │       └── динамик
     │
     ├── irene-Remote
     │       │
     │       └──── WebSocket ────► Irene Server
     │
     └── MPD
```

После запуска клиент подключается к серверу и проходит процедуру согласования возможностей.

При успешном подключении светодиод выключается.

Когда сервер отправляет голосовой ответ:

1. клиент получает ссылку на WAV-файл;
2. скачивает WAV с сервера;
3. при необходимости останавливает MPD;
4. воспроизводит WAV через ALSA;
5. после окончания воспроизведения восстанавливает MPD, если музыка играла до голосового ответа;
6. удаляет временный WAV-файл.

Передача голоса с микрофона выполняется через отдельное WebSocket-соединение, которое сервер предоставляет после готовности серверной STT-службы.

## Индикация светодиодом

Светодиод подключён к GPIO Raspberry Pi.

Используется следующая индикация:

| Состояние                                                 | Светодиод       |
| --------------------------------------------------------- | --------------- |
| Сервер недоступен                                         | Постоянно горит |
| Подключение к серверу установлено                         | Выключен        |
| Отправлена команда управления громкостью, ожидается ответ | Мигание         |
| Получен ответ на команду                                  | Выключен        |
| Соединение потеряно                                       | Постоянно горит |

Таким образом, в обычном состоянии после подключения светодиод не горит.

## Требования

### Аппаратное обеспечение

* Raspberry Pi;
* Seeed 2-Mic Voice Card;
* подключённый динамик;
* микрофон звуковой карты.

### Программное обеспечение

* Raspberry Pi OS;
* Python 3;
* ALSA;
* MPD — если требуется воспроизведение музыки;
* доступ к серверу Irene по сети.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Ujimych/irene-Remote.git
cd irene-Remote
```

Создать виртуальное окружение:

```bash
python3 -m venv irene-Remote
```

Активировать его:

```bash
source irene-Remote/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Настройка

Основные параметры находятся в `config.yaml`.

Актуальная конфигурация:

```yaml
# Irene Remote — connection settings
host: '192.168.1.132'
port: 8086

# Audio input — Seeed 2-Mic Voice Card
buffersize_input: 100
device_input: 'seeed-2mic-voicecard'
blocksize_input: 8000
dtype_input: 'int16'
samplerate_input: 48000
channels_input: 1

# Volume control
volume_step: 5

mixer:
  card: '1'
  control: 'Speaker'

volume:
  min: 0
  middle: 112
  max: 127

  user_min: 76
  user_middle: 112
  user_max: 127
```

### Параметры сервера

`host` — IP-адрес сервера Irene.

`port` — порт WebSocket-сервера.

### Параметры записи

`buffersize_input` — размер внутренней очереди аудиоданных.

`device_input` — устройство захвата звука.

`blocksize_input` — размер блока аудиоданных.

`dtype_input` — формат входных данных.

`samplerate_input` — частота дискретизации.

`channels_input` — количество каналов.

Для Seeed 2-Mic Voice Card используется монофоническая запись:

```yaml
channels_input: 1
```

с частотой:

```yaml
samplerate_input: 48000
```

## Управление громкостью

Управление громкостью реализовано через отдельный механизм `out.volume`.

Архитектура выглядит следующим образом:

```text
Irene Server
     │
     │ out.volume/command
     ▼
plugin_out_volume
     │
     │ OutputChannel
     ▼
plugin_volume_commands
     │
     │ WebSocket
     ▼
gateway.py
     │
     ▼
volume_control.py
     │
     ▼
ALSA / amixer
     │
     ▼
Seeed 2-Mic Voice Card
```

На клиенте аппаратная громкость управляется через:

```bash
amixer
```

с использованием микшера:

```text
Speaker
```

звуковой карты Seeed 2-Mic Voice Card.

### Аппаратный диапазон

Аппаратный регулятор имеет диапазон:

```text
0 ... 127
```

В конфигурации определены следующие значения:

```yaml
volume:
  min: 0
  middle: 112
  max: 127
```

Где:

* `min` — физический минимум;
* `middle` — средний уровень;
* `max` — максимальный уровень.

При запуске клиента автоматически устанавливается:

```text
112
```

### Пользовательская шкала

Для голосового управления используется более удобная шкала:

```text
0 ... 100%
```

Она не соответствует аппаратным значениям напрямую.

В конфигурации:

```yaml
volume:
  user_min: 76
  user_middle: 112
  user_max: 127
```

Соответствие:

```text
Пользовательская шкала     Аппаратное значение

0%                         76
50%                        112
100%                       127
```

Таким образом, аппаратный диапазон ниже `76` не используется для обычного регулирования громкости.

Физический mute при этом использует аппаратное значение:

```text
0
```

### Шаг изменения

Шаг изменения громкости задаётся параметром:

```yaml
volume_step: 5
```

Поэтому команды:

```text
громче
```

и

```text
тише
```

изменяют аппаратную громкость на 5 единиц.

### Голосовые команды

Поддерживаются следующие команды:

#### Увеличение громкости

```text
громче
увеличь громкость
```

#### Уменьшение громкости

```text
тише
уменьши громкость
```

#### Отключение звука

```text
без звука
```

Команда устанавливает физический уровень `0`.

#### Включение звука

```text
звук
```

Команда восстанавливает средний уровень громкости:

```text
112
```

#### Минимальная громкость

```text
минимальная громкость
минимальный звук
```

Устанавливается пользовательский минимум:

```text
0%
```

который соответствует аппаратному значению:

```text
76
```

#### Средняя громкость

```text
средняя громкость
средний звук
```

Устанавливается:

```text
50%
```

и аппаратное значение:

```text
112
```

#### Максимальная громкость

```text
максимальная громкость
максимальный звук
```

Устанавливается:

```text
100%
```

и аппаратное значение:

```text
127
```

## Установка конкретной громкости

Можно установить конкретный уровень громкости:

```text
громкость 45
```

или:

```text
громкость 45 процентов
```

Поддерживаются значения от:

```text
0 до 100
```

При этом сервер передаёт процентное значение клиенту, а клиент самостоятельно преобразует его в аппаратный диапазон `76...127`.

Например:

```text
громкость 45
       │
       ▼
45%
       │
       ▼
аппаратное значение ≈ 99
       │
       ▼
ALSA / Speaker
```

### Распознавание русских числительных

Команда поддерживает не только цифры, но и числа, произнесённые словами.

Например:

```text
громкость пять
громкость двадцать
громкость сорок пять
громкость пятьдесят пять
громкость девяносто девять
громкость сто
```

Поддерживаются значения от `0` до `100`.

Поддерживаются:

* числа от 0 до 19;
* десятки от 20 до 90;
* составные числа, например `сорок пять`;
* `сто`.

Таким образом, голосовая команда не требует точного совпадения с заранее заданной строкой — после слова `громкость` распознаётся числовое значение.

## Получение текущего уровня громкости

Поддерживается команда:

```text
назови уровень громкости
```

Также распознаются варианты:

```text
назови уровень
какая громкость
какой уровень громкости
уровень громкости
```

При получении команды клиент:

1. считывает текущее аппаратное значение `Speaker` через ALSA;
2. преобразует его в пользовательскую шкалу `0...100%`;
3. отправляет текстовый запрос серверу для озвучивания;
4. сервер сообщает текущий уровень голосом.

Например, если аппаратная громкость соответствует `45%`, Irene сообщает:

```text
громкость 45 процентов
```

## Протокол `out.volume`

Для связи сервера с клиентом используется протокол:

```text
out.volume
```

Основные сообщения:

```text
out.volume/command
out.volume/result
```

Команда содержит идентификатор:

```json
{
    "type": "out.volume/command",
    "commandId": "UUID",
    "command": "set",
    "value": 45
}
```

Клиент выполняет команду и возвращает результат:

```json
{
    "type": "out.volume/result",
    "commandId": "UUID",
    "success": true,
    "volume": 45
}
```

Поле `volume` содержит текущую громкость в пользовательских процентах.

Это позволяет серверу получать актуальное состояние громкости после выполнения команды.

## Плагин `plugin_out_volume.py`

`plugin_out_volume.py` реализует клиентскую часть протокола `out.volume`.

Плагин:

* регистрирует протокол `out.volume`;
* создаёт `VolumeOutputChannel`;
* предоставляет серверной части интерфейс управления громкостью;
* отправляет команды клиенту;
* ожидает ответ;
* сопоставляет ответ с исходной командой по `commandId`.

Доступны методы:

```text
volume_up()
volume_down()
volume_min()
volume_middle()
volume_max()
set_volume()
mute()
unmute()
```

Каждая команда возвращает `VolumeCommandResult`.

Результат содержит:

```text
success
volume
muted
```

## Плагин `plugin_volume_commands.py`

`plugin_volume_commands.py` отвечает за обработку голосовых команд управления громкостью на стороне Irene.

Плагин:

* распознаёт команды `громче` и `тише`;
* распознаёт команды mute/unmute;
* распознаёт фиксированные уровни;
* распознаёт команду `громкость + число`;
* преобразует русские числительные в числовые значения;
* запрашивает текущий уровень громкости;
* передаёт команды в `VolumeOutputChannel`;
* сообщает пользователю результат выполнения команды.

Например:

```text
Пользователь:
    громкость сорок пять

        ↓

plugin_volume_commands

        ↓

45%

        ↓

VolumeOutputChannel

        ↓

out.volume/command

        ↓

irene-Remote

        ↓

VolumeControl

        ↓

ALSA / Speaker
```

## Светодиод при управлении громкостью

При обработке команды управления громкостью светодиод начинает мигать.

Например:

```text
громкость 45
      │
      ▼
команда получена
      │
      ▼
LED мигает
      │
      ▼
громкость изменена
      │
      ▼
результат отправлен
      │
      ▼
LED выключен
```

Это позволяет визуально определить, что команда получена и клиент ожидает завершения обработки.

## Запуск

После активации виртуального окружения:

```bash
python main.py
```

При успешном подключении в журнале появляется сообщение:

```text
Подключен к серверу!
```

После установления соединения светодиод выключается.

При запуске также создаются:

* `Recorder`;
* `Player`;
* `MpdPlayer`;
* `VolumeControl`;
* `Gateway`.

## Потеря соединения

Если сервер недоступен при запуске или соединение было потеряно, клиент не завершается.

Он:

1. включает светодиод;
2. освобождает связанные с соединением ресурсы;
3. приостанавливает запись;
4. закрывает дополнительное соединение передачи аудио;
5. пытается подключиться снова через 5 секунд.

При успешном восстановлении соединения светодиод выключается.

## Управление MPD

`mpd_player.py` обеспечивает управление локальным MPD через порт `6600`.

При воспроизведении голосового ответа используется следующая логика:

```text
MPD играет музыку
      │
      ▼
Пришёл голосовой ответ
      │
      ▼
MPD останавливается
      │
      ▼
Воспроизводится голосовой ответ
      │
      ▼
Голосовой ответ закончен
      │
      ▼
MPD запускается снова
```

Для остановки используется именно `stop()`, а не `pause()`.

Это необходимо для полного освобождения ALSA-устройства перед воспроизведением голосового ответа.

Если MPD не воспроизводил музыку до голосового ответа, после него MPD не запускается.

## Воспроизведение голосовых ответов

`player.py` получает WAV-файл с сервера и временно сохраняет его на локальном диске.

Воспроизведение выполняется через:

```text
aplay
```

с использованием ALSA-устройства:

```text
plughw:CARD=seeed2micvoicec,DEV=0
```

Перед воспроизведением при необходимости останавливается MPD.

После завершения воспроизведения временный WAV-файл удаляется.

Ошибки загрузки или воспроизведения не приводят к завершению клиента.

## Запись с микрофона

`recorder.py` использует `sounddevice.RawInputStream`.

Аудиоданные:

1. поступают от звуковой карты;
2. помещаются во внутреннюю очередь;
3. извлекаются из очереди;
4. отправляются серверу через WebSocket.

Используется монофонический вход:

```text
1 канал
```

с частотой дискретизации:

```text
48000 Гц
```

Во время голосового ответа сервер может приостановить передачу микрофона через сообщения:

```text
in.mute/mute
in.mute/unmute
```

### `main.py`

Точка входа приложения.

Создаёт и связывает основные компоненты клиента:

* `Recorder`;
* `Player`;
* `MpdPlayer`;
* `VolumeControl`;
* `Gateway`.

### `gateway.py`

Основной сетевой модуль.

Отвечает за:

* WebSocket-соединение с сервером;
* согласование протоколов;
* получение сообщений;
* обработку голосовых команд;
* обработку команд управления громкостью;
* обработку голосовых ответов;
* управление записью;
* управление светодиодом;
* автоматическое переподключение;
* индикацию ожидания ответа на команды.

### `recorder.py`

Отвечает за захват аудио с микрофона и передачу аудиоданных серверу.

### `player.py`

Отвечает за:

* загрузку WAV-файлов;
* временное хранение;
* воспроизведение через ALSA;
* взаимодействие с MPD во время голосового ответа.

### `mpd_player.py`

Отвечает за управление локальным MPD.

### `volume_control.py`

Отвечает за аппаратное управление громкостью через ALSA `amixer`.

Реализует:

* получение аппаратной громкости;
* установку аппаратной громкости;
* преобразование аппаратного значения в проценты;
* преобразование процентов в аппаратное значение;
* увеличение и уменьшение громкости;
* минимальный, средний и максимальный уровни;
* физический mute/unmute.

### `config.yaml`

Содержит настройки:

* сервера;
* аудиовхода;
* шага изменения громкости;
* ALSA-карты и микшера;
* аппаратного диапазона громкости;
* пользовательского диапазона громкости.

### `requirements.txt`

Содержит Python-зависимости проекта.

Для остановки клиента используется:

```text
Ctrl+C
```

* останавливает запись;
* закрывает WebSocket-соединения;
* освобождает задачи asyncio;
* закрывает соединение с MPD;
